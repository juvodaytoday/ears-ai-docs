---
title: "Get campaign"
api: "GET /user/campaign/{id}"
description: "Get a single campaign by ID"
---

Returns one campaign you own. Response `data` uses the same fields as [List campaigns](/api-reference/campaigns/get-campaigns).

### Path parameters

<ParamField path="id" type="integer" required>
  Campaign ID
</ParamField>

### Response

<ResponseField name="data" type="object">
  Full campaign object including `channel`, `schedule_windows`, WhatsApp/SMS config, and fallback fields.
</ResponseField>

### Error responses

<ResponseField name="404 Not Found">
  Campaign does not exist or does not belong to you.
</ResponseField>
